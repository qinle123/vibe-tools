# 🍅 番茄小说 macOS 终端沉浸式命令行阅读器 (fanqie-reader)

一款专为 macOS 打造的高性能、优雅沉浸、极简稳定的番茄小说（Fanqie Novel）命令行阅读工具。

基于番茄官方网页接口与排版引擎设计，攻克了官方动态字体反爬加密，具备**断点续读**、**智能连读与后台预加载**、**全书目录即时过滤跳转**、**个人本地书架**等丰富特性。

---

## ✨ 核心特性

- 📚 **本地与手机端双向同步书架**：
  - 支持官方扫码登录或 Cookie 导入，支持账号信息与登录态持久化。
  - 按 `S` 或运行 `fq sync` 同步手机端书架与阅读进度；阅读时的位置会自动回写，重新打开前会先读取手机端最新进度。
- 🎯 **精准断点续读**：精确记录阅读行数与章节，下次打开或在书架回车，毫秒级无缝定位恢复。
- 🚀 **智能连读与预加载**：
  - 使用 `h` / `l` 在章节间切换，方向键与翻页键只移动正文位置。
  - 阅读当前章时，后台自动异步预加载下一章正文，翻页零延迟、无卡顿。
- 📑 **全书目录即时检索 (TOC)**：随时按 `t` 键呼出目录浮层，支持直接输入数字或关键词实时模糊筛选匹配章节，回车秒跳。
- 🔍 **全网小说极速检索与优化体验**：
  - 输入法批量出字毫无延迟，回车重新搜索与列表选书彻底解耦。
  - 完美适配 macOS Ghostty、iTerm2、Terminal 的 SS3 方向键。
  - 严格计算 CJK 视觉双列宽，绝不折行溢出破坏终端排版。
- 🔠 **100% 动态字体反爬还原**：完整解析并还原番茄小说 362 个高频混淆汉字，阅读体验无乱码、行云流水。
- 🎨 **极致中文终端排版**：
  - 基于 CJK 真实字宽折行，中文段落前严格双全角空格 `\u3000\u3000` 缩进。
  - 内置标点避头尾法则，杜绝标点符号单独掉到行首。
  - 支持按 `w` 键在 **65列 / 80列 / 100列** 宽度间切换；窄窗口自动适配，调整宽度时尽量保留当前阅读位置。
  - 正文与上下状态栏固定分区，翻行保持断行稳定；仅更新变化的屏幕行，减少闪烁。
  - 采用备用终端屏幕（Alternate Screen Buffer），退出时不污染原有终端历史记录。

## 🚀 快速启动

本工具已配置好全局软链接命令：`fq` 与 `fanqie`。

```bash
# 打开书架
fq

# 快速搜书
fq search 剑来

# 扫码登录账号
fq login

# 一键同步手机端书架与阅读进度
fq sync
```

## 🎮 快捷键操作总览

### 1. 书架界面快捷键
| 按键 | 说明 |
| :--- | :--- |
| `↑` / `↓` | 物理方向键上下移动挑选书籍（打字过滤时优先推荐使用） |
| `j` / `k` | Vim 风格上下移动（在非打字过滤态下可用） |
| `/` | **进入书架快速过滤模式**（输入书名/作者即时筛选，支持物理上下键挑选） |
| `Enter` | 进入选中小说的断点续读（恢复上次读到的行数） |
| `s` | 打开全网小说搜索界面 |
| `L` | 呼出官方账号扫码/Cookie登录与管理面板 |
| `S` | 一键并发同步手机端书架藏书与最新阅读进度（带动态进度条） |
| `d` | 将选中小说的从书架移除（带防误触二次确认） |
| `t` | 直接查看选中书籍的完整章节目录 |
| `r` | 联网刷新选中书籍的最新章节与总章数 |
| `Esc` | 退出过滤模式 / 取消删除确认（绝不误退程序） |
| `q` | 退出程序 |

### 2. 搜索界面快捷键
| 按键 | 说明 |
| :--- | :--- |
| `输入文字` | 实时键入搜索关键词，**光标精准定位，系统输入法候选词浮窗正常弹出** |
| `Backspace` | 删除关键词字符 |
| `Ctrl+U` | 一键清空输入框 |
| `Enter` (输入框) | 触发/重新触发在线搜索 |
| `↓` / `Tab` | 从输入框切换到结果列表，选中第 1 项 |
| `↑` / `↓` | 在结果列表中上下选择；位于输入框时按 `↓` 进入结果列表 |
| `j` / `k` (列表) | 向下 / 向上选择；输入框中作为普通文字输入 |
| `Enter` (列表) | 选定书籍开始阅读并自动加入书架 |
| `a` (列表) | 仅将选定书籍加入书架（留在搜索界面） |
| `Esc` | 返回上一级（书架） |

### 3. 阅读界面快捷键
| 按键 | 说明 |
| :--- | :--- |
| `↓` / `↑` 或 `j` / `k` | 正文内向下 / 向上滚动 1 行，到边界时停留在当前章节 |
| `l` / `h` | 切换下一章 / 上一章 |
| `Space` / `PageDown` | 向下翻页（保留 2 行上下文；到底时停留在本章末尾） |
| `b` / `PageUp` | 向上翻页（到顶部时停留在本章开头） |
| `d` / `u` | 向下 / 向上翻动半屏，并短暂标记新阅读位置 |
| `g` / `Home` | 回到本章开头 |
| `G` / `End` | 跳到本章末尾 |
| `t` | 呼出全书目录（支持实时过滤搜索） |
| `w` | 切换排版列宽（65列 / 80列 / 100列），按窗口宽度自动适配 |
| `a` | 将当前书籍加入 / 移出本地书架 |
| `r` | 强制重新从网络拉取本章正文 |
| `o` | 在浏览器打开番茄官方章节页（正文仅返回试读片段时可用） |
| `?` | 打开快捷键帮助；小窗口可用 `↑/↓` 翻阅，其他键关闭 |
| `q` / `Esc` | 退出阅读并自动保存断点进度 |

## 🛠 命令行指令

```bash
# 打开书架（默认）
fq
fanqie

# 搜索小说
fq search 剑来

# 直接阅读指定 ID 小说
fq read 6927976828237581325

# 官方账号扫码登录（macOS 自动弹出二维码预览）
fq login

# 查看当前登录用户信息
fq login --status

# 命令行一键导入 Cookie 登录
fq login --cookie "sessionid=xxxx; sid_tt=yyyy"

# 注销登录
fq login --logout

# 命令行无头同步手机端书架与阅读进度
fq sync
```

# 直接通过书籍 ID 开启阅读
fanqie read 6918022276038265863

# 查看版本
fanqie --version
```

## 📁 本地数据存储路径

程序产生的所有用户配置与缓存数据均保存在标准家目录下：
- **书架及阅读进度**：`~/.fanqie_reader/bookshelf.json`
- **书籍目录元数据**：`~/.fanqie_reader/chapters/{book_id}.json`
- **章节正文离线缓存**：`~/.fanqie_reader/cache/{book_id}/{item_id}.txt`
